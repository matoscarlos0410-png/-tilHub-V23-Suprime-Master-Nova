1. ¿QUÉ ES ÚTILHUB?

ÚtilHub es una aplicación web que reúne diferentes
herramientas útiles en un solo lugar.

Incluye herramientas para:

- Matemática
- Conversiones
- Tiempo
- Texto
- Organización
- Productividad
- Compras
- Comida
- Diccionario
- Utilidades rápidas
- Herramientas adicionales


2. NOVA FLOW

NOVA FLOW es el sistema visual de ÚtilHub.

En la V23 se amplía hasta:

100 MODOS DE ANIMACIÓN

La animación funciona como fondo global del sitio y puede
permanecer visible mientras el usuario navega por las
diferentes herramientas.


3. DICCIONARIO V23

El diccionario fue mejorado para realizar búsquedas más
rápidas.

Características:

- Búsqueda optimizada.
- Cancelación de solicitudes anteriores.
- Caché de resultados.
- Menor tiempo de espera.
- Definiciones.
- Ejemplos cuando la API los proporciona.
- Sinónimos cuando están disponibles.
- Mensajes claros cuando una palabra no existe.
- Mensajes para problemas de conexión.


4. SIN IA

ÚtilHub V23 NO utiliza inteligencia artificial para realizar
sus funciones principales.

Las herramientas funcionan mediante:

- JavaScript.
- APIs externas cuando son necesarias.
- Almacenamiento local.
- Cálculos realizados directamente en el navegador.


5. INSTALACIÓN

Para utilizar ÚtilHub:

1. Coloca todos los archivos dentro de la misma carpeta.

Archivos principales:

- index.html
- style.css
- script.js
- manifest.webmanifest
- sw.js
- README.txt


2. Abre el proyecto mediante un servidor local o súbelo
   a GitHub Pages.


3. Para utilizar las funciones PWA, el sitio debe funcionar
   mediante HTTPS o localhost.


4. En un navegador compatible aparecerá la opción de
   instalar ÚtilHub como aplicación.


6. GITHUB PAGES

Para publicar ÚtilHub:

1. Crea un repositorio en GitHub.
2. Sube los archivos del proyecto.
3. Entra en Settings.
4. Busca Pages.
5. Selecciona la rama principal.
6. Selecciona la carpeta raíz.
7. Guarda los cambios.
8. Espera a que GitHub publique el sitio.


7. SERVICE WORKER

El archivo:

sw.js

permite almacenar archivos principales en caché.

Esto ayuda a:

- Cargar más rápido el sitio.
- Mantener archivos disponibles sin conexión.
- Actualizar automáticamente la caché cuando cambia
  la versión.
- Preparar ÚtilHub para funcionar como PWA.


8. ALMACENAMIENTO

ÚtilHub utiliza almacenamiento local del navegador para
guardar información como:

- Tema.
- Preferencias de NOVA FLOW.
- Intensidad de animación.
- Rendimiento.
- Favoritos.
- Herramientas recientes.
- Notas.
- Tareas.
- Lista de compras.
- Datos de algunas herramientas.


9. RENDIMIENTO

NOVA FLOW cuenta con diferentes niveles de rendimiento.

El usuario puede elegir una configuración adecuada para
su dispositivo.

En equipos con menos potencia se recomienda utilizar
el modo de rendimiento.


10. PRIVACIDAD

Los datos guardados por ÚtilHub normalmente permanecen
en el navegador del usuario mediante almacenamiento local.

Las herramientas que necesitan servicios externos pueden
realizar solicitudes a sus respectivas APIs.


11. COMPRAS Y COMIDA

ÚtilHub puede ayudar a encontrar opciones de compras
o comida.

ÚtilHub NO realiza automáticamente pedidos ni compras.

El usuario debe revisar la información y realizar el
pedido o compra directamente en el servicio correspondiente.


12. ACTUALIZACIÓN

Cuando se publique una nueva versión:

1. Actualiza los archivos del proyecto.
2. Cambia el nombre de la caché en sw.js.
3. Publica nuevamente el sitio.
4. El nuevo Service Worker eliminará las cachés antiguas.
5. La nueva versión quedará disponible.
